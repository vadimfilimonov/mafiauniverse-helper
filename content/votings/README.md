# votings

Форматирование истории голосований в отдельную читаемую таблицу.

- `votings.js` читает исходную таблицу, строит её копию, объединяет
  переголосования в один блок и поддерживает её актуальность при изменениях
  сайта.
- `votings.css` скрывает исходную таблицу и оформляет созданную копию.

Повторная ничья, после которой игроки остались, отмечается зелёным, а строки
`ушел` и `ушли` отмечают соответствующих игроков алым.
