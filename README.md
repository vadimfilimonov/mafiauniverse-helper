# mafiauniverse-helper

Chrome-расширение для автоматического сохранения текущей игры на MafiaUniverse каждые 5 минут.

## Что делает

- Сразу после перезагрузки страницы игры расширение нажимает кнопку сохранения один раз.
- Затем раз в 5 минут оно сохраняет открытые страницы `https://mafiauniverse.org/Games/Edit*`.
- Используется штатная кнопка `#SaveGameButton`.
- Сохранение выполняется логикой самого сайта: расширение не отправляет собственные запросы на сервер.

## Установка

1. Откройте `chrome://extensions`.
2. Включите **Developer mode**.
3. Нажмите **Load unpacked**.
4. Выберите директорию этого репозитория.
5. Откройте страницу https://mafiauniverse.org/Games/Edit.

## Ограничения

- Вкладка `Games/Edit` должна быть открыта.
- Пользователь должен быть авторизован на MafiaUniverse.
- Расширение не открывает вкладки самостоятельно.
